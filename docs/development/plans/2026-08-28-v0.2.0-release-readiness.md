No new architecture; follow the established `uv` + `hatchling` + `py.typed` + Trusted Publishing OIDC.

**Tech Stack:** Python 3.11+, hatchling, uv, ruff, pyright strict, import-linter, pytest (+ hypothesis, coverage 95%), GitHub Actions (ci.yml, publish.yml), `paxman/py.typed` PEP 561.
